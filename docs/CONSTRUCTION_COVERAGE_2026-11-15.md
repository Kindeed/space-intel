# 在建与规划发射项目覆盖补齐

本轮从“发射场名称”扩展为“发射场—工位/期次—配套工程”的项目目录。预览新增 6 个对象，共 13 个；不声称它们都是 13 座独立发射场，也不把所有项目都标为在建。

| 新增跟踪对象 | 已核实依据与边界 |
| --- | --- |
| 海南商业航天发射场二期三/四号工位 | 2026-10-22 政府网站刊载的报道指出主体工程完成、设备调试，整体投用待后续确认；承建方 2026-07-18 报道三号工位预验收。预验收、竣工、调试及投用不能混同。 |
| 广东阳江发射母港/太空港 | 政府规划提出发射岛、制造基地与母港布局；保留规划依据，未据此判断已开工。 |
| 凉山西部商业航天港 | 2026-04-26 政府来源报道发布规划与合作机遇，仍按规划项目跟踪。 |
| 连云港灌南海上发射技术服务港 | 县政府公开答复提出海上发射平台、码头及总装测试中心，具体开工/审批节点待核对。 |
| 上海火箭星城临沧路码头 | 政府公告确认于 2026-08-31 启动建设，预计工期不是实际完工证明；该码头属于运输/发射回收保障配套，不是发射工位。 |
| 天龙三号酒泉发射工位一期 | 2025-08-07 政府报道已通过竣工验收并完成箭地合练，不列为仍在施工。属地不依据企业注册地或“酒泉”名称猜测。 |

每个项目的 `evidenceUrl`、可核实日期和阶段说明均在 `config/facilities.yaml`，预览“发射场与项目”显示“阶段依据”链接。证据元数据属于项目目录，旧文不补进近期资讯流；没有新公告时仍显示无近期资讯。

新增连续采集入口：中建五局工程新闻、阳江公告/要闻、上海地区动态、灌南公告、凉山政务。施工方补足政府以外的工程进度渠道；这些来源的用途、预期内容与访问风险在 `config/sources.yaml`。六个低相关综合动态入口退出试采，保留配置研究记录，跟踪源总数继续为 150，单轮/每日请求上限仍是 150/600。新来源在旧生产采集中禁用。

额济纳商业航天科研基地等目前只找到不完整的第三方线索，未把它们登记为已批准或在建项目。宁波已补到政府采购网的基础设施项目采购公告作为后续线索，不能仅凭项目名称断言施工启动。温州仍保留“批复待核实”标记。

修复项目匹配：已核实的“临沧路码头”等别名可命中缺少“航天”字样的公告；普通港区施工不会因此全部进入航天流。已在窗口内的元数据可关联新期次，保留原始采集/发布时间，不重复抓正文。测试验证新期次关联和无关施工/消防演练排除。

验证结果与预览运行：待托管验收补记。仅更新草稿 PR #36 的预览分支，未合并生产、未调用生产 D1/health。
