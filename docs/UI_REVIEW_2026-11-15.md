# 近期资讯预览整体与 UI 检查

范围：仅 `codex/recent-aggregation-preview` 和草稿 PR #36。继续 Free，不合并生产，不切换旧 cron，不查询生产 D1 或 health。

## 检查结果与修复

- 公司入口清除旧的地区、项目、领域、类型及关键词组合，避免有资讯却显示空列表。
- 搜索框随网址及浏览器前进/返回同步；未知 view 参数回到资讯页。
- 来源目录默认折叠候选面板，优先呈现已接入来源；新增名称/地区/网站搜索、状态筛选和每批 60 条的展开。筛选与分页均在浏览器完成。
- 发射场与项目支持名称、地区及类型搜索，保留阶段依据和原始公告链接。
- 手机用原生省份选择器，放大元数据与主要触控区域；长名称换行，报批与采购使用独立颜色；目录页压缩重复的大标题，统计区改为紧凑布局，390px 手机首屏可到达资讯列表。
- 省份数量明确为近 30 天口径；重复标题/发布方的摘要不再占用阅读空间，实质补充摘要继续保留。
- 刷新资讯也刷新正在浏览的候选状态；读取候选失败时明确提示保留上次结果。
- 采集边界：共享预算预留失败且尚未发送请求时，保留候选成功日期、种子轮转位置，不把当天标记为已检查。
