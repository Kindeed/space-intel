# 近期资讯预览整体与 UI 检查

范围：仅 `codex/recent-aggregation-preview` 和草稿 PR #36。继续 Free，不合并生产，不切换旧 cron，不查询生产 D1 或 health。

## 检查结果与修复

- 公司入口清除旧的地区、项目、领域、类型及关键词组合，避免有资讯却显示空列表。
- 搜索框随网址及浏览器前进/返回同步；未知 view 参数回到资讯页。
- 来源目录默认折叠候选面板，优先呈现已接入来源；新增名称/地区/网站搜索、状态筛选和每批 60 条的展开。筛选与分页均在浏览器完成。
- 发射场与项目支持名称、地区及类型搜索，保留阶段依据和原始公告链接。
- 手机用原生省份选择器，放大元数据与主要触控区域；长名称换行，报批与采购使用独立颜色；目录页压缩重复的大标题。
- 省份数量明确为近 30 天口径；重复标题/发布方的摘要不再占用阅读空间，实质补充摘要继续保留。
- 刷新资讯也刷新正在浏览的候选状态；读取候选失败时明确提示保留上次结果。
- 采集边界：共享预算预留失败且尚未发送请求时，保留候选成功日期、种子轮转位置，不把当天标记为已检查。

## 验证

- TypeScript、lint、配置一致性和构建通过。
- 本地完整测试：79 文件 / 538 测试通过。
- 浏览器覆盖 1440、820、390、320 宽度：省份/公司交集、关键词前进/返回、政策及领域筛选、公司跨页清理、项目搜索/空结果、来源搜索/状态/分页、候选键盘展开、未知视图回退和快照 503。
- 验收使用真实公开预览快照：283 条资讯、国内 214 条、181 个来源记录、13 个项目对象。无示例新闻补位。
- 截图人工检查桌面资讯和手机来源目录；没有横向溢出、浏览器异常或旧 API/health 请求。
- 浏览来源目录的搜索/状态/展开不新增数据请求。来源分批显示减少初始目录 DOM；正文、图片及 PDF 不下载。
- 云端部署及最终远程验收：待本次预览工作流完成后补记。

## 保留的问题

本轮改善交互，不代表原始来源覆盖已经完整。国内直达发布方仍为 20/214，部分来源连接/解析失败，补充报道仍占多数。政策、项目报批及公司官网继续逐源核对。候选池当前 12 个，尚无通过跨日验证的可接入源；全网搜索及自动配置 PR 未启用。每天四轮更新已配置，持续跨日稳定性仍需实际记录，不能以页面正常显示代替采集成功。
