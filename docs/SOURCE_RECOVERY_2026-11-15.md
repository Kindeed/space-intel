# 官方来源恢复与预览验证

预览：https://recent-aggregation-preview.space-intel.pages.dev/recent 。完整改动仍在草稿 PR #36，禁止合并或切换生产。

## 已核实的问题

上轮 72 个失败入口完成一次有界本地对照：70 个返回 HTTP 200、1 个跳转统一登录、1 个连接超时。HTTP 200 不代表存在日期正确的公告。云端日志确认 ETIMEDOUT、UND_ERR_CONNECT_TIMEOUT、连接重置和 HTTP 403/420。相同 GitHub runner 上 Node 与 curl IPv4 的 8 请求对照不能解决故障；更换客户端不是有效修复。

部分失败来自栏目迁移或页面数据格式：天津、重庆旧入口只是跳转壳；浙江旧审批栏目指向新栏目；烟台原配置实际是辐射许可；宁波审批列表在官方 iframe 引用的公开静态 JSON 中；航天驭星新闻在页面的公开 Nuxt JSON 中。

## 修复

- 核对并修正 6 个公开栏目；新增海南发改项目审批与招投标栏目；统一登录办理入口退出自动采集。现有 150 个跟踪入口及 31 个省级导航入口，不把导航当可采集新闻源。
- 宁波适配器读取官方页面明确引用的静态 JSON，按真实日期、相关标题和官方详情链接筛选；不下载报告书或附件。样本有 9,572 个日期记录，但没有符合窗口的航天标题，故不补造项目公告。
- 航天驭星适配器只读公开页面 JSON 中的新闻元数据，不执行 JS，忽略全文、图片及修改时间。样本最新真实发布为 2026-04-16，不能因为 2026-10-19 修改就标为近期新闻。
- 修复有效载荷、深空、天问等真实任务通知被漏滤的问题，仍排除无关方案、旧日期和未来日期。
- 增加安全的网络/HTTP 错误代码；更换栏目不继承旧 URL 校验器，跳过来源不再残留定时器；切换采集路径仍保留上游限流和明确 HTTP 限制。

## 已有免费服务内的连接路径

Cloudflare 预览节点对国家航天局公告页返回真实 HTML 200；同轮海南审批页仍连接失败。基于该证据，只将 50 个仍报网络/连接超时的来源配置为预览节点读取，未把 403/420 或登录入口加入该恢复批次。

读取路径仅供当前 CI 调用，目标固定为构建时生成的公开来源白名单，只接受 GET，不接收任意目标 URL，不跟随跳转，不转发 Authorization/Cookie，不写数据库。每轮生成临时随机凭据，原值仅留在 CI 忽略的临时文件中；控制对象只存 SHA-256 摘要，不依赖素材桶是否公开。页面和普通浏览器无法调用此路径获取来源页面。

没有新增服务器、套餐或 Cloudflare 绑定；仍使用现有 Pages/R2。采集保持每轮最多 150、每日最多 600 次来源请求，最多 3 并发；连接验证的两次请求也计入共享预算。一次 Node/curl 专项诊断额外使用 8 次请求，无定时任务，已移除临时工作流。公开来源本地诊断共 99 次请求，缓存重放不发请求。

## 最终结果

最新快照检查时间：2026-11-15T02:08:02.890Z（UTC）。共 283 条，国内 214 条，其中国内直链 20 条，占 9.35%；上轮为 14/186（7.53%）。这是可直接跳转发布方的链接比例，不等于已经逐篇鉴定原创版权。

跟踪入口状态：{"ok":87,"error":55,"empty":8,"directory":31}。原 72 个失败入口逐项状态：{"ok":19,"error":47,"empty":4,"retired":2}；退出采集的重复首页/登录入口单列，不能算作修复成功。分类：{"news":267,"procurement":1,"company":15}。

云端完整 77 文件/524 测试及构建通过；远程浏览器在 1440/820/390 宽度验证真实数据、组合筛选、项目/遥测、来源目录和 503 提示，零旧 API/health 请求、零页面错误、无横向溢出。匿名访问来源读取端点返回 401。

已接入中技国际招标的公开关键词检索，核对并采到 2026-11-13 的[海南商业航天发射场（二期）消防车采购原发公告](https://cgci.china-tender.com.cn/zbhw/149682.jhtml)。过滤规则保留发射场消防设备采购，继续剔除普通消防演练。它是采购阶段信息，不能作为项目竣工或新批复证据。

逐项状态见 `source-recovery-evidence-2026-11-15.json`。来源状态是本轮观测，不是长期可用保证。可解析但无近期公告、需要浏览器渲染、上游拒绝访问与连接失败分别保留，不以接入数量声称各省政策或发射场批复已全面覆盖。

## 边界

只部署预览，保持免费方案，不调用生产 D1 或 health，不更改生产主页、旧 cron、其他 bytebaud 服务。此前生产 D1 恢复任务独立保留。每天四次预览更新配置继续有效；本次手动复核不能替代跨日定时稳定性观察。
